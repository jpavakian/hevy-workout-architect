# Contributing

Contributions improving accuracy, clarity or safety are welcome.

## Before opening an issue or pull request

- Use **invented / synthetic** workouts in all public examples.
- Do not attach real user screenshots, personal Hevy history, private exports, account identifiers or API credentials.
- Preserve the principle: **reproduce screenshots, do not redesign**.
- Do not weaken the explicit-approval-before-write rule or copy-by-default behavior without clear maintainer review.
- Describe Hevy compatibility claims as observations only when verified; APIs and catalog features can change.
- Explain any proposed change in a before/after scenario and update the changelog if user-facing behavior changes.
- Do not claim successful exercise lookups, history fetches or writes based on mock examples.

## Suggested pull request checklist

- [ ] Skill YAML metadata is preserved and valid.
- [ ] Set-specific rep targets, failure, drop and timed instructions remain supported.
- [ ] Preview-before-save and explicit approval still apply.
- [ ] Added material contains no personal information or secrets.
- [ ] Documentation and changelog updated if applicable.
