# Security and privacy

This repository is a non-executable instruction skill. It does not include credentials, user account data, or a Hevy connection. A separately authorized integration may be used by a ChatGPT session when available.

**Do not commit** any private workout screenshots, exercise histories, exports, API keys, session cookies, OAuth tokens, personal identifiers or sensitive records.

If you find a possible secret in a public commit, do not publish it in an issue. Remove/revoke the exposed credential through the relevant provider and use GitHub's private vulnerability reporting where configured, or contact the repository maintainer privately. Deleting a file in a new commit does not erase it from Git history.

Issues and pull requests should use fictional, non-identifying reproductions.
